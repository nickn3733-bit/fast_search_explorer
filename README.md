# ⚡ Fast File Search

Надшвидкий нативний пошуковик файлів і папок для Windows на **Rust** з графічним інтерфейсом на **eframe/egui**.

## Можливості

- ⚡ **Пошук за мілісекунди** — паралельний пошук через Rayon із bounded fold/reduce: кожен потік тримає лише топ-1000 кандидатів, тож навіть пошук за однією літерою серед мільйона файлів відповідає за 1–3 мс.
- 🚀 **Фонове багатопотокове індексування** — обхід усіх дисків усіма ядрами процесора через `jwalk`, без фризів UI.
- 💾 **Миттєвий старт із дисковим кешем** — індекс серіалізується у `%APPDATA%\FastFileSearch\index.bin` (bincode). Мільйон файлів завантажується за ~50–80 мс.
- 🔡 **Повна підтримка UTF-8** — роздільні буфери оригінальних імен (`names_display`) та імен у нижньому регістрі (`names_lower`) з окремими офсетами запобігають панікам на кирилиці та будь-яких юнікодних символах.
- 🖱 **Зручне керування:**
  - автофокус на полі пошуку, навігація ↑/↓ та `Enter` для відкриття;
  - контекстне меню (ПКМ): відкрити, відкрити папку з виділенням файлу, копіювати шлях;
  - подвійний клік для відкриття;
- 🗑 **Групове видалення** — ставте галочки на файлах/папках (або «вибрати все» в заголовку), натисніть `Del` чи кнопку «Видалити», підтвердіть — і все летить до Кошика Windows, а не зникає назавжди.
- 🔋 **Нульове навантаження CPU у спою** — пошук виконується лише при зміні запиту або версії індексу.

## Збірка

Потрібен лише Rust (stable, MSVC toolchain):

```powershell
cargo build --release
```

Готовий бінарник: `target\release\fast_file_search.exe`.

Або просто запустити:

```powershell
cargo run --release
```

## Структура коду

| Секція | Вміст |
|---|---|
| `1` | Компактні структури даних: суцільний буфер імен та дедуплікований пул шляхів (28 байтів на запис) |
| `2` | Паралельний пошук на Rayon з bounded fold/reduce |
| `3` | Фоновий обхід дисків через jwalk + кеш bincode |
| `4` | Оперції з файлами: відкриття, `explorer /select` (через `raw_arg` — без типової вади з лапками), копіювання шляху |
| `5` | Головний додаток eframe/egui |
| `6` | Точка входу |
